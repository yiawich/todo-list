# 📝 To-do List

Une application web simple permettant de créer, supprimer et gérer des tâches.

## 🚀 Fonctionnalités

- Ajouter une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée
- Ajouter une tâche avec la touche Entrée

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript

## 📌 Améliorations prévues

- Sauvegarde des tâches avec LocalStorage
- Design responsive
- Animations
