# 📝 To-do List

Une application web permettant de créer, supprimer et gérer des tâches.

## 📸 Aperçu

![Capture de la To-do List](images/screenshot.png)

## 🚀 Fonctionnalités

- Ajouter une tâche
- Supprimer une tâche
- Marquer une tâche comme terminée avec une checkbox
- Ajouter une tâche avec la touche Entrée
- Sauvegarder les tâches avec LocalStorage
- Garder les tâches après actualisation de la page
- Mode sombre avec sauvegarde du choix utilisateur
- Design responsive adapté aux mobiles

## 🛠️ Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git / GitHub
